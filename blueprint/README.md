## 约定

1. **以文档为目标、以实现为准**：两者不一致时先修实现，不擅自改写纲领。
2. **只增不改历史**：已发布的纲领保持原貌；修订以新版本号新增文件，不回改旧文件。
3. **不安装**：`blueprint/` 不随 `install.sh` / `install.ps1` 写入目标仓库，也不参与安装自检。
4. **命名**：`BLUEPRINT-V<major>.<minor>.md`；索引固定为 `README.md`。
